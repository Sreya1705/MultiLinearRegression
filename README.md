# Advertising Sales Prediction using Multiple Linear Regression

# Project Overview

A consumer goods company uses multiple advertising channels to promote its products:

- Television (TV)
- Radio
- Newspaper

The company wants to understand how advertising expenditure across these channels influences product sales and predict future sales based on planned advertising budgets.

In this project, a **Multiple Linear Regression** model is developed to learn the relationship between advertising expenditure and product sales.


## Objectives

The main objectives of this project are:

1. Load and explore the Advertising dataset.
2. Analyze the relationship between advertising channels and sales.
3. Use TV, Radio, and Newspaper advertising expenditure as input features.
4. Use Sales as the target variable.
5. Split the dataset into training and testing data.
6. Build a Multiple Linear Regression model.
7. Predict sales for unseen data.
8. Predict sales for a specific advertising budget.
9. Evaluate model performance using regression metrics.
10. Interpret the model coefficients.
11. Visualize actual sales vs predicted sales.
12. Provide business and technical recommendations.
